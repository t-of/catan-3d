# catan-3d — 立体の盤で遊ぶ陣取りボード

[catan](https://t-of.github.io/catan/) の盤を three.js の立体にした試作。六角タイルの盤で資源を集め、
道・開拓地・都市を建てて競う交代プレイのルールは catan と同じ(下記)。

## 🔗 リンク

- 遊ぶ: https://t-of.github.io/catan-3d/
- 制作: [T.OF...](https://t-of.github.io/)

## 遊び方

カタン基本セットのルールで、3〜6人が1台の画面を回して交代で遊びます。席ごとに「人」か「CPU」（よわい・ふつう・つよい）を選べ、人が1人だけでも遊べます。

- 5人・6人を選ぶと、公式の5〜6人拡張の盤（30マス・港11か所）に自動で変わります。銀行の資源は24枚ずつ、発展カードは34枚になります。
- 5〜6人では、誰かの手番が終わるたびに「特別建設フェイズ」が入ります。手番を終えた人以外が順番に、道・開拓地・都市を建てる／発展カードを買うことだけできます（交易や発展カードを使うのは不可）。建てなければ「パス」で次の人に回ります。
- はじめる前に拡張を「なし」か「航海者版」から選べます。
  - 航海者版は、本島を海で囲み、その外に小島が3つ（各2マス）浮かぶ盤になります。金の川（金鉱）マスは、出目が合えば好きな資源を1枚ずつ選べます（CPUは足りない資源を選びます）。
  - 船は木1・羊1で、海に面した辺で自分の開拓地・都市か自分の船につながる場所に置けます。手番に1回だけ、列の端にある船（置いたばかりでないもの）を別の海の辺へ動かせます。
  - 7や騎士を使うと、盗賊の代わりに海賊を海マスへ動かせます。海賊の隣の辺には船を置けず・動かせず、隣に船がある人から1枚奪います。
  - 小島に初めて開拓地を建てると+2点のボーナスがあります。勝利点は14点、船の上限は15隻、発展カード「街道建設」は道・船どちらでも2本まで建てられます。道・船どちらにも置ける海沿いの辺をタップすると、窓でどちらにするか選べます。
  - CPU（よわい・ふつう・つよい）も船を建てて小島まで進み、最後まで遊べます。7や騎士で盗賊の代わりに海賊を動かしたほうが得なときは、CPU（よわいを除く）も海賊を動かします。
  - 5人・6人でも航海者版を選べます（公式の「航海者 5〜6人用拡張」の簡略版）。本島は5〜6人拡張と同じ30マスになり、周りの海は22マス、小島3つ（各2マス）はそのままです。銀行は24枚ずつ・発展カードは34枚、勝利点は（航海者版のまま）14点です。誰かの手番が終わるたびに入る「特別建設フェイズ」でも、道・開拓地・都市と同じく船を建てられます。
  - サッカー熱は3〜4人だけです（航海者版・5〜6人拡張との組み合わせはありません）。探検家と海賊は5〜6人でも選べます（後述）。
- 「交易と略奪」も選べます（航海者版・サッカー熱・探検家と海賊との組み合わせはありません）。3〜4人は基本の盤（19マス）に足す形で、シナリオを「漁師」「川」「隊商」「蛮族の襲撃」から1つ選びます。公式ルールブック（Traders & Barbarians）の「キャンペーン」4つを実装しました（5つ目の最終シナリオ「Traders & Barbarians」はさらに規模が大きいため見送りました）。
  - 漁師（勝利点10点。古い靴を持つ人は11点）: 砂漠の代わりに湖（出目2・3・11・12のどれでも反応）を盤の中央側に置き、外周に漁場6か所（出目4・5・6・8・9・10）を置きます。盗賊は最初の7が出るまで盤の外にいます。魚トークンは1匹11枚・2匹10枚・3匹8枚（計29枚）に古い靴1枚を混ぜた山から引き（開拓地1枚・都市2枚）、7匹を超えて持つと一番少ない手持ちと入れ替わるだけです。交易のボタンから、2匹で盗賊を盤外へ、3匹で誰かから資源を1枚奪う、4匹で銀行から資源を1枚、5匹で道を1本只で（置く場所は自分で選べます）、7匹で発展カードを1枚只でもらえます。古い靴を引いた人は、サイコロを振った自分の手番に、自分と同点以上の人へ渡せます（自分だけが最多点のときは渡せません）。
  - 川（勝利点10点）: 盤の真ん中の列を横切る川が流れ、川沿いの頂点に開拓地・道を建てるたびに金貨1枚（都市への建て替えでは増えません）。川をまたぐ辺には橋（土2・木1）が要り、架けると金貨3枚もらえます（橋は3本まで。発展カード「街道建設」では架けられません）。手番に2回まで、金貨2枚で資源1枚に替えられます。銀行と交易して資源を金貨にすることもできます（4資源で1枚。3:1の港なら3資源。2:1の港は使えません）。金貨が一番多い人だけ「富豪」で+1点、一番少ない人は「貧者」で-2点です（同点なら、その全員が貧者になります。はじめは全員0枚で同点なので、最初は全員が貧者です）。
  - 隊商（勝利点12点）: 砂漠の代わりに盤の中心へオアシスを置き、そこから3本のキャラバンが伸びます。開拓地を建てる・都市にするたびに、手番の終わりにラクダを1つ置きます。置き場所は投票で決め、手番を終えた人から順に、羊・麦を出して票を入れます（出さなくても参加できます）。一番多く出した人（同点なら、手番を終えた人）が置き場所を選びます。ラクダと同じ辺の道は、最長交易路の数え方で2本ぶんになり、ラクダに挟まれた頂点の開拓地・都市は+1点です。盗賊は最初の7が出るまで盤の外にいます。
  - 蛮族の襲撃（勝利点12点）: 盤の中心を「砦」にします（産出せず、征服もされません）。開拓地を建てる・都市にするたびに「蛮族が上陸」し、7でない出目を3回まで振って（同じ出目は数えません）、その出目のマスに蛮族を1体置きます。3体たまったマスは「征服」され、産出が止まり、隣に道・開拓地を新しく置けなくなります（全方向を征服されると、その開拓地・都市も得点になりません）。騎士は羊1・鉄1で砦の6辺のどれかに建て、手番に1回、最大3歩（麦1枚払えば5歩）まで動かせます（砦の辺をふさいだままだと新しい騎士を建てられないので、必要なら空けます）。手番の終わりに、蛮族のいるマスごとに「隣の6辺にいる騎士の数＞蛮族の数」なら退け、その蛮族を捕虜にできます（複数の人が関わっていれば、騎士の多い人を優先し、同数ならランダムに分けます）。捕虜2人につき勝利点1点です。盗賊は使わず、7が出たら相手を選んで資源を1枚奪います。発展カードは基本と同じ山を使いますが、騎士は（公式の専用カードでなく）直接建てる形にしたので、発展カードに騎士は入れていません。
  - CPU（よわい・ふつう・つよい）は、漁師では魚が貯まるとおおむね得なタイミングで使い、川では金貨が貯まると欲しい資源に替え、隊商では投票に参加してラクダを自分の得になる場所へ置き、蛮族の襲撃では資源があれば騎士を建てて蛮族のいるマスへ寄せ、最後まで遊べます。
  - 5人・6人でも交易と略奪を選べます（公式の「交易と略奪 5〜6人用拡張」の近似。正確な公式の数は資料がないため、他の5〜6人拡張と同じ比率で増やしました）。盤は5〜6人拡張と同じ30マスになり、オアシス・砦は（19マス盤と同じく）内陸の中心寄りのマスに置かれます。銀行は24枚ずつ・発展カードは34枚になります。漁師は漁場が9か所に増え、魚トークンの山も1匹14枚・2匹13枚・3匹10枚（計37枚）+古い靴1枚に増えます（砂漠が2つになりますが、湖にするのは1つだけです）。蛮族の襲撃は蛮族の供給が36個に増えます。勝利点はどのシナリオも3〜4人のときと同じです。誰かの手番が終わるたびに入る「特別建設フェイズ」でも、道・開拓地・都市・発展カードの購入にくわえ、蛮族の襲撃の騎士の建設・移動もできます。
  - 省いた点・近似にした点（公式ルールブックの Traders & Barbarians、2015年版を参照）
    - 5つ目の最終シナリオ「Traders & Barbarians」（隊商and蛮族を組み合わせ、荷馬車・商品トークンを使う最も複雑なもの）は見送りました（ルールブック1324行目〜）。
    - 5〜6人用拡張の正確な公式の数（漁場の数、魚トークンの枚数、蛮族の供給数など）は資料がなく、資源の銀行が19→24枚になる比率に近い形で近似しました。
    - 川・隊商・蛮族の襲撃の盤は、公式の専用フレーム（川の分岐・沼地タイル、沿岸の輪＋砦の固定レイアウトなど）でなく、基本の19マス盤に手を加える簡略な形にしています（ルールブック785-813行目、1127-1143行目）。川をまたぐ辺の正確な場所・数（公式は7か所）も近似です。
    - 漁師の魚トークンの「できるだけ無駄なく払う」判断、川の「銀行と資源⇔金貨の交易で相手プレイヤーとのやり取り」（対人のみ・公式にはあります）、隊商の「2つのキャラバンが合流する」規則、蛮族の襲撃の「砦の6辺の組ごとに1体だけ退却させる」細かな規則（ルールブック1279-1294行目）は省き、より簡単な形（蛮族の襲撃では毎回1体をランダムに退却）にしました。
    - 蛮族の襲撃の騎士の移動・退却の判定は、公式の「向き合う辺の組」の仕組み（砦を挟んだ6辺を3組に分ける。ルールブック1282-1294行目）を使わず、関わった騎士からランダムに1体を選ぶ形にしています。
- 「都市と騎士」も選べます（航海者版・交易と略奪・サッカー熱・探検家と海賊との組み合わせはありません）。3〜4人は基本の盤（19マス）のまま、次のルールが足されます（5〜6人の盤については後述）。
  - 都市の商品: 森・牧草・山に接する都市は、資源1枚にくわえて商品（紙・布・硬貨）を1枚産みます。畑・丘に接する都市は、これまでどおり資源2枚です。
  - 都市の発展: 交易（布）・政治（硬貨）・科学（紙）の3系統を、商品を払って1〜5段階まで上げられます（n段階目は商品n枚）。都市を1つも持っていないと上げられません。4段階目で「大都市」（+2点。1系統につき1つの都市だけに置かれ、段階で上回られると印だけ奪われますが、5段階目に届けばもう奪われません。蛮族の襲来でも、大都市の置かれた都市は守られます）になります。交易を3段階目にすると、商品2枚で銀行から好きな資源か商品を1枚もらう2:1交易ができます。政治を3段階目にすると騎士を「最強」まで昇格できます。科学を3段階目にすると、7以外の目で自分に資源・商品が1枚も入らなかったとき、あとで好きな資源を1枚もらえます。
  - 騎士: 羊1・鉄1で建て、麦1で起動します。起動中の騎士だけが、隣の頂点への移動・隣にいる自分以下の強さの相手の騎士を追い出す・盗賊が自分の都市に接しているときに盗賊を砂漠へ追い払う、ができます（使うと移動と追い出すはその手番の残り回数を使い切り、盗賊払いは騎士自身が休みになります）。羊1・鉄1で昇格でき、最強にするには政治を3段階目以上にしておく必要があります。弱い・強い・最強、それぞれ2体まで（公式どおり）持てます。
  - 事件のサイコロ: 毎回、資源の2つのサイコロと別に3つめのサイコロ（蛮族の船×3面、交易・政治・科学の城門×各1面）を振ります。蛮族の船が出ると蛮族が1歩進み、7歩で襲来します。城門が出ると、資源サイコロの1つめの目以上にその系統を発展させている人は進歩カードを1枚引きます。
  - 蛮族の襲来: 起動中の騎士の強さの合計（弱い1・強い2・最強3）が、全員の都市の数（大都市を含む）以上なら勝ち、一番貢献した人に「守護者」点+1（同点なら進歩カードを引きます）。足りなければ、貢献が一番少なかった人の都市が1つ開拓地に戻ります（大都市の置かれた都市は守られます）。襲来のあとは騎士が全員休みます。最初の襲来までは、7が出ても盗賊は動きません（捨てるだけ）。
  - 進歩カード: 交易・政治・科学の色ごとに山があり、各10種類×2枚＝20枚（計60枚）。公式の54枚そのままの構成ではなく、効果がはっきり分かる種類だけを選んだ簡略版です。手札は4枚まで持てます（勝利点のカードは引いたときにすぐ公開され、手札には数えません）。
    - 省いたカード（公式にあるがこの版にはないもの）: 持続・妨害系のカード（外交官・司教・間者・改心者・ワルロードなど、相手の手番や盤面に長く影響するもの）、発展カードと差し替える系（印刷機など）。盤に常時表示する仕組みが要るため、今回の版では見送りました。
  - 城壁: 土2で、都市1つにつき1つまで、最大3つ建てられます。持っている数×2枚ぶん、7が出たときに捨てずに済む枚数が増えます（例: 1つで9枚まで）。
  - 勝利点は13点です。最長交易路・最長の開拓地・都市の数え方は基本のままで、最大騎士力のボーナスはありません。
  - CPU（よわい・ふつう・つよい）は、資源に余裕があれば騎士を育てて起動・昇格させ、都市の発展を進め、商品が余れば交易3段階目の2:1交易も使い、簡単な進歩カード（相手選びが要らないもの）を使いながら最後まで遊べます。
  - 5人・6人でも都市と騎士を選べます（公式の「都市と騎士 5〜6人用拡張」の簡略版）。盤は5〜6人拡張と同じ30マスになり、銀行の資源は24枚ずつ、商品の銀行は13枚ずつ、進歩カードは各色とも3枚ずつ（計90枚）に増えます。誰かの手番が終わるたびに入る「特別建設フェイズ」でも、道・開拓地・都市と同じく騎士の建設・起動・昇格、都市壁、都市の発展ができます。勝利点は（都市と騎士のまま）13点です。蛮族の襲来の強さ比べ（起動中の騎士の強さ合計 対 全員の都市の数）も、人数なりにそのまま使います。
- 3〜4人では「サッカー熱」も選べます（航海者版・5〜6人拡張・都市と騎士・交易と略奪との組み合わせはありません）。公式シナリオ CATAN – Fußballfieber の実装です。勝利点は11点です。
  - 盤は砂漠を抜き、盤の中心と、出目「2」だったマスの2か所をサッカー場にします（産出しません）。抜いた「2」のチップは、出目「12」のマスにもう1枚足され、そのマスは2か12のどちらでも産出します。盗賊は漁師シナリオと同じく、最初の7が出るまで盤の外にいます。
  - 開拓地・都市をサッカー場に接して建てる（建て替えも含む）たびに、持ち駒（攻撃の回数）が1枚増えます（最初は1枚、上限6枚）。
  - 誰かが開拓地・都市を建てると、その手番の終わりに必ず1回「試合の節」が行われます（1手番で何回建てても1回だけ）。その節の組み合わせで対戦する2人ずつが、持ち駒の枚数ぶん攻撃し（1回ごとに五分の確率でゴール）、ゴール数が多いほうが勝ちです（勝ち3点・負け0点・引き分けは1点ずつ）。この点はすぐ「フットボールレーン」を進み、いくつかのマスを通ると資源か発展カードのボーナスがあります。4人は15節、3人は12節で終わり、レーンの終点に先に届いた人がいれば、そこでシーズンが早く終わります。
  - 節の終わりに、フットボールレーンの順位で勝利点が付きます（1位+3点、2位+2点、3位+1点、4位+0点。同点はその順位を分け合い、次の順位はその人数ぶん飛ばします）。この点は試合のたびに付け直されるので、開拓地を建てて11点に届いても、その手番の終わりの試合で順位が落ちれば勝利は確定しません。
  - CPU（よわい・ふつう・つよい）は、持ち駒・試合・順位点をすべて自動で進めるだけなので、選ぶことはなく、最後まで普通に遊べます。
  - 省いた点・近似にした点（公式ルールブック、2023年版を参照）
    - 専用のサッカー場の台紙・持ち駒（両面チップ）の実物の投げ合いは使わず、持ち駒の枚数ぶん五分の確率で判定する形に置き換えました（ルールブック66-86行目）。
    - 対戦カードを決める「スペイルタグ表」（物理の表）は使わず、4人は3節で全6組が一巡、3人は3節でダブルプレイヤー（2試合こなす人）が一巡する、循環式の計算に置き換えました（ルールブック36-48行目）。
    - 3人戦で、ダブルプレイヤーが最初の試合の結果を採用するか見送るか選べる規則（ルールブック160-196行目）は省き、常に両方の結果を数える簡略化にしました。
    - フットボールレーンの通過ボーナスは、公式は資源を自分で選べますが、簡略化してランダムに1種類もらう形にしました。レーンの長さ・ボーナスの位置も、専用ボードでなく簡略な計算に置き換えています。
- 「探検家と海賊」も選べます（都市と騎士・交易と略奪・サッカー熱との組み合わせはありません）。盤は航海者版と同じ（3〜4人は本島19マス＋海18マス＋小島6マス）ですが、小島の6マスは最初「霧」で伏せられ、地形も数字も分かりません。
  - 船（木1・羊1）を小島に面した海へ置く・動かすと、隣の霧のマスが明らかになります。見つけたマスの資源を1枚もらえます（金の川のマスなら、ランダムな1種類）。霧のままの島には開拓地を建てられません（まず船で見つける必要があります）。
  - 探検ミッション: 霧のマスを最初に3つ見つけた人は+1点です（一度決まると変わりません）。小島に初めて開拓地を建てると（航海者版と同じく）+2点のボーナスもあります。
  - 盗賊・海賊は霧のままのマスには動かせません（見つかっていないマスを襲えないため）。勝利点は14点です。
  - CPU（よわい・ふつう・つよい）は霧のマスを選ばずに盗賊・海賊を動かし、ほかは航海者版と同じ判断で船・陸を使い分けて最後まで遊べます。
  - 5人・6人でも探検家と海賊を選べます（公式の「探検家と海賊 5〜6人用拡張」の近似。正確な公式の数は資料がないため、航海者版の5〜6人対応と同じ比率で近似しました）。本島は5〜6人拡張と同じ30マスになり、周りの海は22マス、小島3つ（各2マス、霧）はそのままです。銀行は24枚ずつ・発展カードは34枚、勝利点は（探検家と海賊のまま）14点です。誰かの手番が終わるたびに入る「特別建設フェイズ」でも、道・開拓地・都市と同じく船を建てられます。
  - 省いた点・近似にした点（公式ルールブック CATAN – Seafarers: Explorers & Pirates を参照）
    - 海賊の隠れ家の討伐（海賊船との戦闘・強さの投資）、金塊・漁の専用ミッションチップ（魚・香辛料・布のミッションを含む複数種類）、原住民の集落や交易所、上陸用ボートは見送り、霧の探索＋金の川＋1種類の探検ミッションだけの簡略版にしました。
    - 金の川で得られる資源は、公式は好きな種類を選べますが、簡略化してランダムな1種類にしました（既存の航海者版の金の川は選べるままです）。
    - 専用の六角形チップを裏向きに置いて1枚ずつめくる実物の仕組みではなく、船が隣接したら自動でめくる形にしています。
- 最初に開拓地と道を2個ずつ置きます（1周目は順番、2周目は逆順）。
- 手番: サイコロを振る → 出た目の資源をもらう → 道・開拓地・都市・発展カードを建てる/交易する → 手番を終わる。
- 7が出たら、手札8枚以上の人は半分捨て、盗賊を動かして隣の1人から1枚奪います。
- 交易は銀行・港（3:1 か 2:1）のほか、相手を選んで出す・もらう資源を決める簡単な形です。相手がCPUのときは、その場の内容が得かどうかでCPUが受ける・断るを決めます。
- 得点が10点に届いたら勝ちです（開拓地1点・都市2点・最長交易路+2点・最大騎士力+2点・勝利点カード1点）。
- 盤面をタップして開拓地・道・都市・盗賊の場所を選びます。下のボタンでサイコロ・建設・交易・発展カード・手番終わりを操作します。

## 盤の見た目

盤は六角タイルの並びでなく、ドローンで斜め上から撮った島の空撮写真のように見せている（表示だけ。
判定・ルールは 2D 版の catan と同じデータを使う）。地形は森・牧草地・麦畑・丘・山・砂漠で見た目が違い、
木・羊・麦畑の畝・丘の段々・山の岩肌とがれ場などを実物の縮尺で細かく置く。海は岸のそばが明るいエメラルド、
沖が濃紺になる深さのグラデーションで、岸には白い泡が寄る。太陽は低い午後の角度で、長い影と薄い霞がかかる。

- 道・開拓地・都市には持ち主の色の旗・雨戸・日よけ布・標柱の布が付き、遠目でも誰のものか分かる。
- 出目の数字はマス中心に埋め込んだ低い石碑に彫ってあり（6・8 は赤い顔料）、カメラが遠いときだけ
  石碑の上に半透明の数字ラベルが控えめに重なる。
- 盗賊は黒い外套の一団とマスに落ちる暗い影、海賊（拡張）は黒い帆の船と海面の暗い影で居場所が分かる。
- 置ける頂点・辺・マスや、盗賊を動かせるマスは地面に沿った細い光の線・輪で示す。持ち主色の淡い輪郭線
  （道・開拓地・都市の足もと）は、駒を置く場所を選んでいる・盗賊を動かしている・タップ/ホバー中だけ出す
  （盤の右下の設定ボタンで「いつも表示」にも切り替えられる）。
- 画質は URL の `?q=high`（既定は `mid`）か、同じ設定ボタンの「画質」で選べる（保存は次の読み込みから反映）。

## アプリとして入れる（PWA）

- iPhone / iPad: Safari で開き、共有 → 「ホーム画面に追加」
- Android / PC の Chrome・Edge: 画面の「アプリにする」ボタン、またはアドレスバーのインストールボタン

## 開発

ビルド不要。フォルダをそのまま静的サーバで開く。

```sh
python3 -m http.server 8000   # → http://localhost:8000/
```
